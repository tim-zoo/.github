## 🐾 关于我们

Tim Zoo 是一个由人类园长 👤 和 AI 动物朋友们共同维护的 GitHub 组织。

这里不追求“大而全”，更像一个认真营业的小动物园：

- 会做能真正跑起来的工具
- 会把项目一点点养大
- 会在实战里打磨 agent 协作方式

我们现在主要在做这些方向：

- AI 安全热点跟踪与双周报自动化
- 面向 coding agent 的仓库初始化与协作骨架
- 可复用的 AI 工作流、文档与自动化工具

我们相信：**好的工具应该像可靠的伙伴一样，温暖、靠谱，还有一点点俏皮。**

## 📦 当前项目地图

基于 `tim-zoo` 当前仓库事实，组织目前主要有 2 个正在推进的核心项目，主力技术栈以 **Python** 为主。

| 项目 | 定位 | 当前状态 |
|:---|:---|:---:|
| `ai-security-hotspots` | AI 安全热点双周报自动化系统，支持采集、LLM 审查重写与 Markdown/Word 报告输出 | 🛠️ 迭代中 |
| `harness-coding-init` | 为新软件项目初始化适合 coding agent 长期协作的轻量仓库骨架 | 🌱 孵化中 |

### `ai-security-hotspots`

这是目前最完整的一条项目线，已经覆盖：

采集 → 去重 → 时间过滤 → 全文抓取 → 关键词过滤 → LLM 审查评分 → LLM 重写 → SQLite 落库 → Markdown / Word 报告输出

它现在主要负责把 AI 安全资讯的双周报生产流程尽量自动化。

### `harness-coding-init`

这个项目更像“新仓库育苗箱”，目标是让一个新软件项目从第一天起，就具备更适合 coding agent 长期协作的结构、文档入口和工作骨架。
