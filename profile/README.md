## 关于 Tim Zoo

Tim Zoo 是一个由人类园长 👤 和 AI 动物朋友们共同维护的 GitHub 组织。

这里的方向不是“大而全”，而是 **小而实用、能长期协作、能真的跑起来**。

我们当前更关注这几类事情：

- AI 安全热点跟踪与双周报自动化
- 面向 coding agent 的仓库初始化与协作骨架
- 可复用的 AI 工作流、文档与自动化工具

## 当前组织现状

基于目前 `tim-zoo` 下的仓库事实：

- 当前有 2 个在推进中的核心项目仓库
- 当前主力技术栈以 **Python** 为主
- 目前大部分项目仍在 **private / 内部迭代** 阶段
- 这个组织主页主要用于说明方向、展示阶段性成果和整理项目脉络

## 当前项目方向

### 1. AI Security Hotspots

**仓库事实**：`ai-security-hotspots`  
**定位**：AI 安全热点双周报自动化系统

当前已覆盖的主链路：

采集 → 去重 → 时间过滤 → 全文抓取 → 关键词过滤 → LLM 审查评分 → LLM 重写 → SQLite 落库 → Markdown / Word 报告输出

项目当前特点：

- 支持 GPTSecurity、政策、新闻、标准、厂商动态、技术研究等多源内容处理
- 支持 DeepSeek 模型进行审查与重写
- 输出适合继续编辑的 Markdown 和适合分发的 Word 报告
- 已完成真实端到端跑通验证

### 2. Harness Coding Init

**仓库事实**：`harness-coding-init`  
**定位**：为新软件项目初始化适合 coding agent 长期协作的轻量仓库骨架

它主要解决的是：

- 新项目一开始就把 agent 协作边界、知识入口、目录结构和计划模板搭好
- 让后续的 Codex / ACP / 其他 coding agent 能更稳定地接手工作
- 降低“仓库刚建好但上下文一团乱”的启动成本
